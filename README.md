# 分镜调度台 / Storyboard Director

面向 AI 漫剧制作的轻量分镜预演工具：梳理人物的空间位置、朝向与走位，制作简单的镜头运动参考，帮助编写提示词的 AI 理解拍摄意图。

## 为什么做这个项目

用文字讨论 AI 漫剧的分镜时，人物站在哪里、面向谁、如何移动，以及镜头从哪里拍、怎么运动，常常需要反复解释。

这个工具让创作者先把人物和机位摆出来，用时间轴编排角色与镜头，再播放一个简化预演。导出的调度图、镜头图或预演视频，可以作为视觉参考提供给负责写提示词的 AI，让空间关系和运动路径更容易理解。

## 解决什么问题

- **厘清人物空间关系**：通过俯视场景安排角色位置、朝向、走位与机位，查看人物之间及人物与镜头的关系。
- **把运镜意图演示出来**：使用时间轴与关键帧编排人物和摄像机路径，在 2D / 3D 镜头视图中预演简单运动。
- **给提示词 AI 提供可看的参考**：导出俯视调度图、当前镜头图和预演视频，减少单靠文字描述空间与运动的歧义。
- **保留可修改的编排**：通过工程 JSON 保存和重新打开场景，继续调整人物与镜头。

输出用于表达分镜与调度意图，是简化的制作参考；创作者可以将其交给提示词 AI，再开展后续视频制作。

## 开始使用

双击 `index.html` 或 `启动.bat`，使用 Edge / Chrome 打开。手动分镜功能无需安装、无需联网。

- 俯视调度、角色动作、朝向与摄像机轨迹。
- 2D / 3D 镜头预演与时间轴编辑。
- 导出项目 JSON、俯视图、镜头图及 WebM 预演视频。

## 可选 AI 编排

安装 Node.js 18+，复制 `ai-config.example.json` 为 `ai-config.json`，填写自己的本地 ComfyUI 或兼容 API 设置，再运行 `启动AI.bat`。AI 功能为可选增强，不影响手动使用。API 密钥只填在自己电脑上，`ai-config.json` 已被 Git 忽略。

完整操作与更新说明见 [使用说明](docs/完整使用说明.md)。

## 项目文件

- `index.html`：浏览器入口。
- `css/`、`js/`：界面、调度、渲染、导出与 AI 编排源码。
- `ai-proxy.js`：本机 AI 代理，使用 Node.js 内置模块。
- `downloads/storyboard-director.zip`：可直接解压使用的源码包。
